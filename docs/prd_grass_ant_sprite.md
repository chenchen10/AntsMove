## 1. 功能背景

当前「普通路边小草蚁」（ant_id=1）的素材存在以下问题：
- **视角错误**：现有素材为侧视角，但游戏为2D俯视角，导致视觉不协调
- **风格不统一**：与蓝色默认蚂蚁（up/down帧）的品质差距明显
- **无动画帧**：缺少上下行走的3帧动画，仅有单张静态图
- **细节不足**：身体分区模糊，腿/触角细节粗糙

需要重新设计一套高品质的俯视角草蚁素材，对齐现有蓝色蚂蚁的品质标准。

---

## 2. 核心目标

| 目标 | 量化标准 |
|------|----------|
| 视角统一 | 俯视角（与blue_ant一致），身体朝上为基准 |
| 品质对齐 | 细节丰富度不低于blue_ant_up1.png（390x388） |
| 动画完整 | 上行3帧 + 下行3帧 = 6张精灵图 |
| 风格协调 | 卡通写实混合风格，与现有昆虫精灵（ladybug/bee等）一致 |
| 缩放兼容 | 源图256x256+，缩放至40x40后仍可辨识身体结构 |

## 4. 详细设计需求

### 4.1 蚂蚁类型定义

**普通路边小草蚁**是游戏中最基础的新手蚂蚁，设计需体现：
- **普通感**：不华丽、不威猛，但干净可爱
- **草地特征**：体色偏绿/黄绿色调，呼应"草蚁"名称
- **小体型**：相比后期蚂蚁，整体比例偏小偏轻盈

### 4.2 视觉规范

#### 身体结构（俯视角，头朝上）

| 部位 | 描述 | 尺寸比例 |
|------|------|----------|
| **头部** | 圆形，略小于胸部，有两只复眼和一对触角 | 占身体约20% |
| **胸部**（并胸腹节） | 椭圆形，连接头与腹，6条腿从此处伸出 | 占身体约25% |
| **腹部**（后腹部） | 最大的椭圆形，有节段纹理 | 占身体约35% |
| **腿**（6条） | 前2+中2+后2，有关节弯折，爪尖细 | 左右对称分布 |
| **触角**（2根） | 膝状弯曲，从头部前方伸出 | 长度约头部1.5倍 |

#### 颜色方案

| 部位 | 主色 | 暗部 | 高光 |
|------|------|------|------|
| 头部 | `#7CB342` 草绿 | `#558B2F` 深绿 | `#9CCC65` 亮绿 |
| 胸部 | `#8BC34A` 黄绿 | `#689F38` 暗黄绿 | `#AED581` 浅黄绿 |
| 腹部 | `#689F38` 橄榄绿 | `#33691E` 深橄榄 | `#7CB342` 草绿 |
| 腿 | `#5D4037` 棕色 | `#3E2723` 深棕 | - |
| 触角 | `#4E342E` 深棕 | `#3E2723` 黑棕 | - |
| 复眼 | `#212121` 黑色 | - | `#FFFFFF` 白色高光点 |

#### 光影效果

- **光源方向**：左上方45度
- **腹部高光**：左上区域有椭圆形高光带
- **头部高光**：左侧有小圆形高光
- **腿部阴影**：腿下方有1px深色投影
- **整体轮廓**：1-2px深色描边，增强缩放后的辨识度

### 4.3 动画帧设计（6帧）

#### 上行帧（up1/up2/up3）- 朝上行走

| 帧 | 腿部姿态 | 身体位移 |
|----|----------|----------|
| up1 | 左前+右中+左后 腿伸展，其余收拢 | 正常位置 |
| up2 | 所有腿居中（过渡帧） | 轻微上下浮动（±1px） |
| up3 | 右前+左中+右后 腿伸展，其余收拢 | 正常位置 |

#### 下行帧（down1/down2/down3）- 朝下行走

| 帧 | 腿部姿态 | 身体位移 |
|----|----------|----------|
| down1 | 与up1镜像（腿姿态交换） | 正常位置 |
| down2 | 所有腿居中（过渡帧） | 轻微上下浮动（±1px） |
| down3 | 与up3镜像（腿姿态交换） | 正常位置 |

**动画节奏**：帧间隔0.15秒（现有代码已设定），行走时腿交替摆动产生蠕动感。

### 4.4 技术规格

| 参数 | 值 |
|------|-----|
| 源图尺寸 | 256x256 像素（最小），推荐390x390与blue_ant对齐 |
| 格式 | PNG，RGBA 8-bit，透明背景 |
| 缩放目标 | 40x40（ANT_SIZE） |
| 输出路径 | `images/ant_processed/ant1_up1.png` ~ `ant1_down3.png` |
| 命名规则 | `ant1_up{1,2,3}.png` / `ant1_down{1,2,3}.png` |
| 背景 | 纯透明（alpha=0），无白色/浅色底 |
| 去背要求 | 抗锯齿边缘平滑，无白色残留像素 |

## 5. 规则定义

### 5.1 素材加载规则（已有代码兼容）

```python
# assets.py 中的加载逻辑（无需修改）：
# ant_images[1] = assets.get('ant_1', fallback_img)
# 如果存在 ant_1_up1/ant_1_down1 等帧，需在assets.py中构建帧列表
```

**关键约束**：
- 现有代码通过 `ant_images[ant_id]` 加载单张基底图
- 动画帧需要通过 `blue_ant_up_frames` / `blue_ant_down_frames` 类似的帧列表机制
- **如需支持每只蚂蚁独立动画帧**，需修改 `assets.py` 的 `load_assets()` 函数

### 5.2 缩放规则

```
原始尺寸 → smoothscale → 40x40 → 去背处理 → 游戏内使用
```

- 使用 `pygame.transform.smoothscale` 缩放
- 缩放后执行 `_remove_background()` 去除残留背景
- 敌方蚂蚁额外叠加红色色调（已有代码处理）

### 5.3 边界规则

| 场景 | 处理方式 |
|------|----------|
| 素材文件不存在 | 回退到代码生成的简单绿色蚂蚁（现有_fallback逻辑） |
| 素材尺寸不匹配 | 自动缩放至TARGET_SIZES['ant']=(40,40) |
| 透明通道异常 | _remove_background() 会检测并处理 |

---

## 6. 异常处理

| 异常 | 处理 |
|------|------|
| PNG文件损坏 | try/except捕获，回退到代码生成 |
| 尺寸过小（<64px） | 警告：缩放后细节丢失，建议最小256px |
| 非RGBA格式 | 自动convert_alpha()转换 |
| 命名不规范 | 不会被加载到ant_images映射中 |
