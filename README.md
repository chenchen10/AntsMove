# 蚂蚁抢甜点

一款基于 Pygame 的休闲策略对战游戏。玩家率领蚂蚁军团，穿越多种地形，与 AI 蚂蚁对抗抢夺甜点资源，在限时内达成金币目标通关。支持 26 种蚂蚁、200 个关卡、8 种地形，拥有完整的养成、任务、成就、签到系统。

## 游戏特色

- **26 种蚂蚁**：每种蚂蚁拥有独立的搬运/速度/防御三属性，以及专属特性（地形免疫、击退、抢夺等）
- **200 个关卡**：四大阶段递进（新手开荒 → 过渡养成 → 中期攻坚 → 终极挑战），每 10 关切换地形
- **8 种地形**：平原、林地、沙漠、山地、热带丛林、工地、树栖高空、寒冰高原，各有独特负面效果与克制关系
- **星级评定**：1-3 星评价体系，基于通关速度与收集率综合判定
- **双金币体系**：对战金币 + 通关奖励，支撑完整的商店经济循环
- **丰富系统**：每日/每周任务、5 维度成就、7 天签到周期、商店购买与属性升级

## 环境要求

- Python 3.12+
- Pygame

## 快速开始

```bash
# 克隆项目
git clone <repo-url>
cd AntsMove2

source .venv/bin/activate

# 或安装依赖
```

## 核心玩法

### 基本操作

1. 在关卡选择界面选择关卡
2. 编队：从已拥有的蚂蚁中选择上阵阵容（数量受关卡限制，最多 30 只）
3. 开始对战：蚂蚁自动寻路、采集甜点、返回研磨机交付
4. 在限时内收集足够金币并击败 AI 即可通关

### 地形系统

| 地形 | 负面效果 | 适配蚂蚁特性 |
|------|---------|------------|
| 平原 | 无 | 无 |
| 林地 | 减速 | 啃食速度 +20% |
| 沙漠 | 减速 + 高温 + 干旱 | 免疫所有沙漠效果 |
| 山地 | 减速 | 爬坡无减速，移速 +20% |
| 热带丛林 | 减速 + 高温 | 啃食效率 +30% |
| 工地 | 重物减负 | 搬运重物无减速 |
| 树栖高空 | 攀爬减速 | 攀爬无减速，移速 +30% |
| 寒冰高原 | 冰冻 + 减速 | 免疫冰冻减速 |

### 战斗系统

- **击退**：部分蚂蚁拥有击退概率（10%/20%），将敌方推离当前位置
- **僵直**：碰撞可能造成敌方短暂僵直，防御属性可减少僵直时间
- **抢夺**：高级蚂蚁可概率抢夺敌方携带的甜食

### 养成系统

- 三属性独立升级（搬运/速度/防御），每属性最高 200 级
- 升级费用按梯度递增，速度和防御升级费用比搬运便宜
- 同种蚂蚁可购买多只

## AI 系统

- 敌方蚂蚁从当前梯队固定池中生成，固定种子保证同关卡永远同样阵容
- 只镜像玩家【数量】，不镜像种类和属性
- 敌方属性 = 蚂蚁基础值 × 阶段倍率 × 递进系数（每 10 关 ×1.12），封顶 90% 满级值
- 151 关后全体敌方获得额外 Buff（地形负面减免、僵直减免）

## 存档系统

- JSON 本地持久化，支持 v1 → v2 → v3 → v4 → v5 版本自动迁移
- 原子写入（先写临时文件再 rename），防止存档损坏
- 数据涵盖：蚂蚁拥有/属性、关卡星级、任务进度、成就进度、签到记录
